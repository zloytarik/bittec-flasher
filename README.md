\# Bittec Flasher



Незалежна десктопна утиліта з графічним інтерфейсом для автоматичного очищення файлів параметрів (`.param`/`.parm`), прошивки польотних контролерів (`.apj`) та надійної двопрохідної заливки параметрів по протоколу MAVLink із фінальною звіркою.



Розроблено проєктом \*\*\[Bittec](https://bittec.com.ua)\*\* для контролерів, сумісних з ArduPilot / Pixhawk.



\## Основні можливості



\* \*\*Очищення параметрів перед заливкою:\*\* автоматично видаляє read-only, лічильники (`STAT\_\*`), апаратні ідентифікатори датчиків (`\*\_DEVID`) та автооновлювані параметри (`BARO\*\_GND\_PRESS`, `INS\_\*\_CALTEMP`), зберігаючи окремий лог видалених рядків (`\*\_removed.txt`).

\* \*\*Режим для серії бортів:\*\* опційне видалення індивідуальних калібрувань акселерометра, гіроскопа, компаса та датчика повітряної швидкості.

\* \*\*Двопрохідна заливка з перезавантаженням:\*\* спочатку записуються базові параметри підсистем (зокрема `GPS1\_TYPE`, `GPS2\_TYPE`, `SERIAL\*\_PROTOCOL`), після ребуту активуються залежні параметри й виконується другий прохід — це усуває проблему часткового неперенесення налаштувань GPS.

\* \*\*Автоматична фінальна звірка:\*\* зчитує параметри назад із контролера після перезавантаження та формує текстовий звіт (`\*\_verify\_report.txt`) з окремим блоком перевірки `GPS\*` і `SERIAL\*\_PROTOCOL`.

\* \*\*Автономний запуск на Windows:\*\* готовий `.exe` у розділі \[Releases](https://github.com/zloytarik/bittec-flasher/releases) не потребує встановлення Python.



\## Завантаження та використання (Windows 10/11)



1\. Завантажте `BittecFlasher.exe` зі сторінки \*\*Releases\*\* (перевірте контрольну суму у файлі `SHA256SUMS.txt`).

2\. За потреби покладіть ваші файли прошивки (`.apj`) та параметрів (`.param`/`.parm`) поруч із `BittecFlasher.exe` або оберіть їх через кнопку \*\*«Обрати...»\*\*.

3\. Закрийте програми, що можуть займати COM-порт (Mission Planner, QGroundControl, PuTTY).

4\. Натисніть \*\*«Підготувати та прошити»\*\* і підключіть контролер напряму до USB-порту ПК.



> \*\*Примітка щодо Windows SmartScreen:\*\* оскільки файл не має комерційного цифрового підпису, при першому запуску Windows може показати попередження. Натисніть \*\*«Докладніше» → «Виконати в будь-якому разі»\*\* або зберіть `.exe` самостійно з вихідного коду нижче.
